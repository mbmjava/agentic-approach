# Plans

One living plan per active workstream: `working-docs/plans/<name>.md`. Start from
[`docs/standards/templates/plan.md`](../../docs/standards/templates/plan.md).

Keep each plan current enough to resume from without this session's memory — latest outcome, the next
decision, and the next action — and delete it when the workstream closes.
