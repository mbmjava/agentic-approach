# Plans

One living plan per active **cross-cutting workstream spanning multiple specs**:
`working-docs/plans/<name>.md`. A single spec keeps its plan and wave log in its own `## Plan` and `## Waves`
sections. Start cross-cutting plans from [`docs/standards/templates/plan.md`](../../docs/standards/templates/plan.md).

Keep each plan current enough to resume from without this session's memory — latest outcome, the next
decision, and the next action — and delete it when the workstream closes.
