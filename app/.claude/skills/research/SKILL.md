# Research spec

1. Run the shared `spec-base` interview in order.
2. Ask the question to answer or decision to inform, candidate hypotheses, evidence/measurement that would
   distinguish them, time-box, and intended deliverable.
3. Make clear whether the outcome authorizes implementation or only informs a later spec.
4. Write one draft requirement. Do not infer product policy or start implementation before approval and
   preflight.
