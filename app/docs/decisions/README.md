# Decisions (architecture decision records)

Hard-to-reverse choices live here as ADRs, one file per decision: `NNNN-short-title.md` (zero-padded,
e.g. `0001-...`). Start from the [decision template](../standards/templates/decision.md).

An ADR records **Context → Decision → Consequences** — the durable "why" behind a choice. Keep the debate
that produced it out of the record. A choice that is easy to reverse belongs in the plan, not here.
