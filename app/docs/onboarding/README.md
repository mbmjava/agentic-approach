# Onboarding

A short path for a new contributor (human or agent) to get productive here:

1. Read [`AGENTS.md`](../../AGENTS.md) — the always-loaded entry — and
   [`WORKING-AGREEMENT.md`](../../WORKING-AGREEMENT.md).
2. Read [`docs/00-index.md`](../00-index.md) — the documentation map.
3. Read [`working-docs/agent-standards.md`](../../working-docs/agent-standards.md) — how agents work here.
4. Run the checks in [`AGENTS.md`](../../AGENTS.md) → **Verify** to confirm your environment.
5. Start from the current [`working-docs/handoff.md`](../../working-docs/handoff.md) and the active plan.

Add project-specific setup steps (accounts, local services, a first task) below the generic path.
