# Vibe — discuss an idea

Use this for exploration, options, constraints, and trade-offs. Do not write a requirement, select an
`approval_mode`, create a plan, or dispatch implementation workers. When the owner says the idea is ready for
formal work, identify its type and hand it to the matching formalizer: `/feature`, `/enhancement`, `/bugfix`,
`/infra`, or `/research`.
