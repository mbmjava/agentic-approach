# Enhancement spec

1. Run the shared `spec-base` interview in order.
2. Ask what exists today, what should change, why now, how success is measured, and what must remain
   compatible or migrate.
3. Identify the smallest shippable increment and out-of-scope behavior.
4. Write one draft requirement from the approved answers. Do not begin implementation until spec review and
   wave-start preflight are complete.
