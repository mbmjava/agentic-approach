# Agentic Approach site

The public-facing guide and starter overview, built with Vite, React, TypeScript, and Tailwind CSS v4.

```sh
npm ci
npm run dev
```

Build and type-check:

```sh
npm run build
```

## GitHub Pages

The `Website` workflow checks pull requests and deploys `main` to
<https://mbmjava.github.io/agentic-approach/>. In repository settings, set **Settings → Pages → Build and
deployment → Source** to **GitHub Actions** once before the first deployment.
